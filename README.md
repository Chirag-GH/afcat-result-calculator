# AFCAT 2026 Result Calculator

[Open AFCAT Result Calculator](https://colab.research.google.com/github/Chirag-GH/afcat-result-calculator/blob/main/afcat-2026-result-calculator.ipynb)

A Python-based tool that extracts question-level data from an AFCAT answer key PDF and automatically calculates the following:

1. **Final Score**
2. **Correct**
3. **Attempted**
4. **Incorrect**
5. **Unanswered**

## Limitations

Works with the current **AFCAT 2026 answer key PDF format** and may require changes if the PDF layout or formatting changes.
